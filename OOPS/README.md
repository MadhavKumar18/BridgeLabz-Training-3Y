# OOP Assignment 8 – JavaScript Solutions

This folder contains separate JavaScript solutions for all 9 questions in the supplied assignment.

## Files
1. Q1_Student_Result_Processing.js
2. Q2_Online_Food_Ordering.js
3. Q3_Product_Discount_System.js
4. Q4_Employee_Inheritance.js
5. Q5_Ride_Sharing_Application.js
6. Q6_ECommerce_Inventory_System.js
7. Q7_Banking_Application.js
8. Q8_Movie_Ticket_Booking_System.js
9. Q9_Fitness_App_Analytics.js

## How to run
Open Terminal in this folder and run an individual file with Node.js:

```bash
node Q1_Student_Result_Processing.js
```

Replace the filename to run another question. Each file includes test data and console output.

## Notes
- The grade thresholds in Q1 are: A (80+), B (60–79.99), C (40–59.99), F (below 40).
- The fare rate in Q5 is set to ₹12 per kilometre because the assignment does not specify a rate.
- The low-stock threshold in Q6 is set to fewer than 5 units because the assignment does not specify a threshold.
