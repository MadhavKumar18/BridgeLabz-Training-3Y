# jQuery Assignment 9

This project contains solutions for all 10 questions in `Lec27-29 JQuery Assignment.pdf`.

## Files
- `q1.html` … `q10.html`: separate page for each question.
- `q1.js` … `q10.js`: separate JavaScript/jQuery file for each question.
- `styles.css`: shared responsive styling.

## Run
1. Extract the ZIP archive.
2. Open any `qN.html` file in a modern browser, or use VS Code Live Server.
3. Internet access is required because the pages load jQuery from the official jQuery CDN.
4. For Question 10, email uniqueness is demonstrated using the browser's localStorage. Clear site data to reset the demo.

## Notes
- Each question is implemented independently.
- The pages use semantic HTML5 elements and include at least five applicable sample items.
- Key jQuery logic is documented with comments in each JavaScript file.
- Question 9 isolates jQuery 1.12.4 and jQuery 3.7.1 with `noConflict(true)` so both versions can be used without sharing the global `$`.
