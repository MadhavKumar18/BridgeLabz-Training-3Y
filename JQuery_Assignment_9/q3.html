What is jQuery?

jQuery is a JavaScript library that simplifies DOM manipulation and event handling.

How do I include jQuery?

Include the jQuery library with a script tag, then load your own script.

What does .on() do?

.on() attaches event handlers to selected elements.

What is a selector?

A selector targets HTML elements so jQuery can work with them.

Can jQuery create elements?

Yes. jQuery can create, append, prepend, and remove DOM elements.
